Alert rules

Grafana cannot take alert rules pasted into its pages. Push them from above, or load them one of two ways:

As a provisioning file

For a Grafana you run: save this in its provisioning/alerting/ directory and restart it. Rules loaded this way can be changed only in the file.

Download alerts.json

Through Grafana's API

Download rule-group.json and send it with a service-account token (Editor role) into a folder that exists; the folder's uid is the last part of its address in Grafana.

curl -X PUT "{{ connection.url if connection.configured else 'https://grafana.example' }}/api/v1/provisioning/folder/FOLDER_UID/rule-groups/{{ group }}" \
  -H "Authorization: Bearer $GRAFANA_TOKEN" \
  -H "Content-Type: application/json" \
  -H "X-Disable-Provenance: true" \
  --data @rule-group.json
